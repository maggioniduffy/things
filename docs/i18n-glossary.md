# Copy glossary — English / Spanish (rioplatense)

Spanish UI uses **voseo** (guardá, abrí, probá, tenés), sentence case, short and warm, never literal.
Product names: Thingteca (en) / Cosateca (es); the email sender is "Teca". Never translate the brand.
